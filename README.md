# SOC Home Lab: Wazuh

## Overview
A home lab built to practise SOC analyst skills: log collection,
detection, alert triage, and investigation.

## Lab Architecture
- **Ubuntu Server**: Wazuh manager and dashboard
- **Windows 10**: monitored endpoint with the Wazuh agent
- **Virtualisation:** [VMware]

## Tools
Wazuh, Ubuntu Server, Windows 10
